# 博客改版计划

## 方向

参考 [nelson.co](https://nelson.co/) 的留白、窄栏排版、简洁栏目切换和文字列表，使用本站自己的头像、文章与 GuitarPal 内容。亮色采用白底与低对比度辅助文字；暗色继续跟随系统设置。

## 实现

1. 先将本计划存为 `docs/plans/2026-09-27-blog-redesign.md`，再修改站点。
2. 统一全站页头、导航、正文宽度、字体层级和页脚。首页顶部展示头像、姓名及简短身份介绍；文章阅读页沿用同一视觉语言，保持舒适的正文排版。
3. 首页设置「文章／项目／关于」三个栏目，默认按年份列出文章。栏目通过 URL 锚点切换，支持直接链接和浏览器前进后退；禁用 JavaScript 时，各栏目仍可顺序阅读。
4. 「项目」只展示 GuitarPal 的简短介绍与官网链接，使用其官网现有图标。`/projects/` 同步改为真实项目列表，并移除模板示例项目。
5. 保留 `/blog/` 分页、`/archive/`、现有文章网址及 `/en/` 英文首页；这些页面共用新版样式。现有邮箱、微信、GitHub 和 RSS 入口继续可用。

## 验证

运行 `bundle exec jekyll build`，检查首页栏目切换、直接打开锚点、文章分页、旧网址和外部链接；分别查看桌面与手机宽度、亮色与暗色，并检查键盘导航和无 JavaScript 状态。

## 约定

首页不新增文章主题分类：目前 42 篇文章几乎都属于同一分类，且没有标签。GuitarPal 项目文案依据其[现有官网](https://guitarpal.app/)整理，不展示占位作品。
